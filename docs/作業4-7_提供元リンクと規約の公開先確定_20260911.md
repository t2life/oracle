## 3. 事業者情報の確定と、公開文書の完成（2026-09-11）

### 3.1 決定

| 項目 | 決定 |
|---|---|
| 事業形態 | **個人事業主**（法人登記は行わない） |
| 販売事業者・運営責任者 | 本名を表示。屋号 `Apps2Craft` のみでは特商法の「氏名または名称」を満たさないため |
| 所在地・電話番号 | 自宅住所・携帯番号を表示（バーチャルオフィスは契約しない方針） |
| 管轄 | **福岡地方裁判所**（利用規約 第12条） |
| 動作環境 | Android 7.0（API 24）以上／iOS 15.0 以上（ビルド設定の実値） |

### 3.2 実値をリポジトリに置かない仕組み

**`t2life/oracle` は公開リポジトリである**（`gh repo view` で確認）。
氏名・住所・電話番号を本文へ直接書くと、**一度コミットした時点でgit履歴から消せない**。

∴ 次の形にした。

```text
docs/仕様書/14・15・09    … 本文。実値の位置は差し込み記法で空けてある
scripts/business_info.local.json  … 実値（.gitignore 済み・コミットされない）
scripts/business_info.example.json … ひな形（コミットする）
scripts/build_legal_site.py … 生成時に差し込む
site/                        … 生成物（.gitignore 済み・実値を含む）
```

生成器は実値ファイルが無ければ**生成せずに止まる**（空欄のまま公開しないため）。
未知の差し込み項目があっても止まる（欠けたまま公開ページができないため）。

利用規約は管轄を裁判所名の直書きに変えたので、**住所を規約に書かずに済んでいる**。
実際、生成された `terms.html` に住所・電話番号は含まれない（氏名も含まない）。

### 3.3 プライバシーポリシーの書き直し（Ver.1.0 → Ver.1.1）

Ver.1.0 は社内の実装棚卸しの体裁で、`models.py`・`User`・`AuthAccount` 等の
クラス名と内部資料名がそのまま本文にあった。**内容は変えずに**利用者向けの
文章へ書き直し、あわせて次の2件を反映した（初版の時点では存在しなかった）。

- **相談内容の保存**（2026-09-10 承認）
- **機種引継ぎコード**（2026-09-11 追加）

実装の現況（外部連携が未接続・退会APIが未実装・監査ログの自動削除が未実装）は
「実装メモ」として文書内に残し、**公開ページには載せない**。

### 3.4 残る制約

**3文書とも法務レビューは未実施**である（各ドラフトが自ら明記している）。
ストア公開前に専門家の確認を行うこと。
