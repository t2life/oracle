# 作業1-3 問いと結果が繋がらない — 調査と方針

作成日: 2026-09-12
ご指摘: 「宝くじで1等を当てたい」という問いに対し、結果が繋がっていない。
当選確率は努力で動かせないため助言ができない。できるとすれば運気を高めることだけである。
カードの解釈をそちらへ持っていくか、利用者の直感で解釈が進むよう導く回答にする必要がある。

## 1. 事実確認 — 現在の出力を再現した

`宝くじで1等を当てたい` ／ テーマ=金運 ／ 3枚引きで実際に合成した結果:

```text
「宝くじで1等を当てたい」という問いに、いま整えるべきなのは、次の流れです。

【過去】天之御中主神。…【現在】高御産巣日神。…【未来】神産巣日神。…

続いて、天之御中主神と神産巣日神は「浄化」の関係にあります。…

天之御中主神は宇宙の中心・根源・無限の可能性を通じて、
　　　　　　　　　　　　　　　　　　　お金の使い方を見直す時期を示しています。 ← ★

アドバイス：育てることを意識してみてください。 ← ★

小さな一歩から始めてください。
```

**宝くじの問いに「お金の使い方を見直す時期」（＝節約の話）が出ている。**
問いとまったく関係がない。

## 2. 原因 — コードレベルで3つ

### 2.1 分類が外れると「日替わりの無関係な段落」が出る（最大の原因）

`services/interpretation_engine.py`

| 行 | コード | 何が起きるか |
|---|---|---|
| L133-155 | `_classify` が `質問タイプ分類`（19行）のキーワードを走査 | 金運の3状況は「収入・給料・昇給」「投資・株・資産」「支出・節約・固定費」。**宝くじはどの語にも当たらない** |
| L156 | 一致0件なら `return theme_genre, None, …` | 状況＝`None` |
| L426 | `pattern = patterns[_stable_hash(date_key, theme_id) % len(patterns)]` | 状況が無いので**日付でテンプレを選ぶ**。金運の3件から機械的に1件 |

∴ 「お金の使い方を見直す時期」は、**問いを読んでいない。日付で選ばれただけ**である。
これは相談内容がある場合に**必ず**起きる（分類に外れた問い全て）。

### 2.2 助言がカードの語をそのまま出すだけ

L203-218 `_action_sentence` は `keyword_dict.action` の語を順番に差し込む。
`アドバイス：{action}ことを意識してみてください。` という1つの型しか無く、
**問いの性質を一切見ていない**。だから「育てることを意識して」になる。

### 2.3 自力で動かせない問いという概念が無い

現状のマスタは「ジャンル（何の話か）」しか持たない。
**「自分の行動で変えられるか」という軸が無い**ため、
努力で動かせない問い（抽選・確率）にも行動助言を返してしまう。

## 3. 調査 — 占いの実務ではどう扱うか

### 3.1 コントロール外の問いは「言い換える」のが定石

- 「はい／いいえ」を迫る問いや運命を丸投げする問いは避け、
  **「どうすれば良い方向へ進むか」へ変換する**と実用的な答えになる。
- **ギャンブルの勝敗そのものをカードで占うのは避ける**とされる。
  運や確率に左右される事柄は、カードが映す「流れ」「心理」とは性質が異なるため。

∴ オーナーのご指摘（「助言ができない。できるとすれば運気を高めることだけ」）は
**実務の定石と一致している**。

### 3.2 当選を断定する鑑定文は、法律事務所が注意喚起する詐欺の典型

「必ず当たる」等を鑑定文に出す占いサービスは、消費者被害の相談先の記事で
**典型的な手口として名指しされている**。当否を断定してはならない。

### 3.3 姉妹アプリ（十二天水地暦）に既に規律がある

同じオーナーの先行アプリは**主線が宝くじそのもの**で、次の規律を持つ。

> `engine/advice_module.py` L25
> **当選を保証する断定表現は用いず、行動のタイミング・方法のみを述べる**

（`docs/117_修正方針…` §運用リスク3 でも「当選を保証する表現の禁止」として再掲）

∴ 本アプリに移植すべき既存資産がある。新しく考える必要はない。

## 4. 方針

### 4.1 「問いの扱い」という軸を1つ足す（型だけを持つ・実体はカードから）

新シート **`問いの扱いマスタ`** を作る。
オーナーのDBマスタ更新と衝突しないよう、既存シートには手を触れない。

> **★2026-09-12 オーナー指示による修正**
> マスタが持つのは**判定語と型だけ**とする。**文面の実体は必ずカードから引く**
> （属性・エレメント・キーワード）。カードと無関係な定型文をマスタへ置くことは**禁止**。
> ∴ 既存の `_fill_placeholders` の差し込み語をそのまま使い、`{属性}` `{エレメント}` を足す。

| 列 | 内容 |
|---|---|
| 区分 | `運任せ` / `分類外` |
| キーワード | 判定語（`運任せ` のみ）。宝くじ・くじ・抽選・当選・一等・ギャンブル・馬券・競馬・パチンコ・スロット |
| 語り口 | 文脈テンプレの位置に置く段落の**型** |
| 助言 | アドバイス行の**型** |

差し込める語は**すべてカードの列**である。

| 差し込み | カードの出どころ |
|---|---|
| `{神名}` | `name_ja` |
| `{属性}` | `attribute`（別天神/創造神 など） |
| `{エレメント}` | `element`（エーテル・火・風・水・地） |
| `{基本的意味}` | `basic_meaning` |
| `{キーワード}` | `keywords` |
| `{肯定的キーワード}` `{中立的キーワード}` `{行動提案ワード}` | `keyword_dict` |

**カードが変われば文面の実体が変わる。** 型だけが共通である。

### 4.2 分類に外れたら、日替わりのテンプレを出さない

原因2.1 の直接の修正。`compose_reading` L418-426 を次のようにする。

| 状態 | 変更前 | 変更後 |
|---|---|---|
| 相談内容あり・状況が一致 | テンプレを出す | **同じ**（変更なし） |
| 相談内容あり・`運任せ` に該当 | 日付でテンプレを選ぶ | **`運任せ` の型**（カードの語で満たす） |
| 相談内容あり・どれにも外れる | **日付でテンプレを選ぶ** | **`分類外` の型**（同上） |
| 相談内容なし（本日の託宣） | 日付でテンプレを選ぶ | **同じ**（問いが無いので無関係にならない） |

### 4.3 直感へ導く（ご指摘の後半）

行動を指図せず、**利用者自身の直感で解釈が進むよう導く**。
言い訳と読まれる前置き（「当たるかどうかは動かせません」等）は**置かない**。

改善後の見込み（天之御中主神＝属性「別天神/創造神」・エレメント「エーテル」の場合）:

```text
「宝くじで1等を当てたい」という問いに、いま整えるべきなのは、次の流れです。

【過去】天之御中主神。…【現在】高御産巣日神。…【未来】神産巣日神。…

続いて、天之御中主神と神産巣日神は「浄化」の関係にあります。…

天之御中主神が宿すのはエーテルの力。別天神/創造神として、
選択の時・転換期のあなたを照らしています。 ← 語り口（属性・エレメント由来）

あなたの中の「瞑想する」という感覚に従って進めてみてください。
中心に立つ・統合するへと流れが向かうでしょう。 ← 助言（キーワード由来）

日々の小さな選びに、その直感を使ってみてください。
```

**同じ問いでもカードが変われば、属性もエレメントもキーワードも変わる**ため、
文面はカードに従って変わる。マスタは型しか持たない。

### 4.4 当選の断定を機械で止める（姉妹アプリの規律の移植）

`禁止表現マスタ`（現在18語）へ当選断定の語を追加する。

| 追加語 | 理由 |
|---|---|
| 当選し / 当選する / 当たります / 高額当選 | 当否の断定。§3.2 の詐欺手口と同じ表現になる |

既存の「必ず」「絶対」と同じ扱いで、全文を機械走査するテストに載せる。

## 6. リスク

### 占いとしての妥当性

1. **当否を断定してしまう** → 禁止表現へ当選断定を追加し、全44柱×全区分の生成文を機械走査（§4.4）
2. **突き放した印象になる**（「動かせません」だけで終わる） → 受け止めの直後に必ず助言と締めを置く。3文で1組とし、マスタで型を固定する
3. **判定語の行き過ぎ** → 「当たる」は「思い当たる」等に誤爆するため**採らない**。「宝くじ」「抽選」「当選」など名詞を中心に置く

### システム

1. マスタ未整備でも落ちない → 区分が引けなければ従来どおり（fail-soft）
2. サーバーとオフラインの食い違い → パリティテストで一字一句を固定。宝くじのケースを期待値へ追加
3. 分類に外れた問いで段落が減る → 減った分は直感へ導く一文が埋めるため、文量は保たれる

### 運用

1. 文面の調整 → マスタの型を直すだけ。アプリ更新は不要
2. 判定語の追加 → `問いの扱いマスタ` に行を足すだけ
3. 多言語 → 型は当面日本語のみ。en/zh では従来の助言（組み合わせ解釈・番号の読みと同じ扱い）
