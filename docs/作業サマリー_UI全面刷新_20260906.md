|---|---|
| 起動オープニング約10秒 | `SplashScreen`（新設・10秒）: 星空の瞬き→3枚のカード扇展開＋金環パルス→明朝金タイトル→タグライン→フェードアウト。環境音再生・**スキップ可**。終了後オンボーディングへ |
| 指でシャッフル | `ShuffleScreen`全面書換: 12枚のカード雲が**指のパン操作に連動して渦巻く**（撹拌度に応じ回転加速・ハプティクス・シャッフル音）。累計スワイプ量が閾値到達で金発光＋「指を離してください」→**指を離して1.2秒で自動完了**（仕様書9.6の3条件を実ジェスチャーから計測しAPIへ実値送信） |

| カード展開〜結果 | 横一列のカード（時差スライドイン・微角度）をタップ→**3Dフリップ**（透視変換rotateY・裏→表）→結果画面が**段階リビール**（カード表面→テーマ/デッキ→キーワード→解釈文→ボタン、チャイム音） |
