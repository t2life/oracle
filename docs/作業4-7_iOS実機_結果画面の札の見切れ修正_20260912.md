## 1. 作業4: 実装

### 1.1 ② 結果画面上部の札（U-09）

**変更**: `mobile_app/lib/features/reading_result/presentation/reading_result_screen.dart`（`_TopCards`）

複数枚の結果で `PageView` の各ページに置く札を `FittedBox` で包んだ。
`PageView` がページに強制する「表示幅×0.66 × 高さ336」の枠の中で、札は本来の縦横比
（`kOracleCardAspect`＝120/70）のまま、枠が広ければ原寸で中央に、狭ければ縮小して置かれる。

- 1枚引き（`Center` で包んでいる分岐）は変更なし
- 「両隣の札を少し覗かせる」（`viewportFraction: 0.66`）は変更なし
- 共通部品 `OracleCardFace` は変更なし

### 1.2 ① シャッフル音（参考・未コミット）

`SoundService.play` に `restart` 引数を追加し、シャッフル音だけ「鳴っている間は打ち切らない」ようにした。
**実機で「途切れて雑音に聞こえる」まま**だったため、コミットせず再方針とした（原因は再方針書 §1）。

### 1.3 iOS の署名設定

`mobile_app/ios/Runner.xcodeproj/project.pbxproj`

- `DEVELOPMENT_TEAM = D7THUVNT5T;` を Runner の Debug / Release / Profile に追加（Xcode の Signing & Capabilities で設定）
- `objectVersion = 54` → `60`（Xcode 26.5 がプロジェクト形式を更新）

Team ID は署名済みアプリに含まれる公開情報で、個人情報には当たらない。
これにより Mac で clone したあと Team を設定し直さずに実機ビルドできる。
