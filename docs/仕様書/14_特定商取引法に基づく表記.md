## 2. 表記本文（案）

| 項目 | 内容 |
|---|---|
| 販売事業者 | 【要確定】（個人事業主の場合は氏名、法人の場合は法人名） |
| 運営責任者 | 【要確定】 |
| 所在地 | 【要確定】（個人事業主は請求があった場合に遅滞なく開示する旨の記載に代えられる） |
| 電話番号 | 【要確定】（同上。請求時開示の記載に代えられる） |
| メールアドレス | support@apps2craft.com（仮。オラクルアプリ専用窓口を設ける場合は変更） |
| 販売価格 | 各商品ページ・アプリ内課金画面に表示する価格（消費税込）。チケット: 300円（初回お試し30枚）/500円（20枚）/1,000円（50枚）/2,000円（120枚）、サブスクリプション: 月額500円（7日間無料トライアル付き） |
| 商品代金以外の必要料金 | アプリのダウンロード・利用に伴う通信費（お客様負担） |
| 支払方法 | App Store / Google Play のアプリ内課金（各ストアの決済手段に従う） |
| 支払時期 | 購入手続き完了時（サブスクリプションは各ストアの規定に基づき自動更新時に課金） |
| 商品の引渡時期 | 決済完了後、直ちにアプリ内で利用可能 |
| 返品・キャンセル | デジタルコンテンツの性質上、購入確定後の返品・返金はお受けできません。返金は各ストア（App Store / Google Play）の返金ポリシーに従います |
| サブスクリプションの解約 | 各ストアの定期購入管理画面から解約手続きを行ってください。アプリを削除しても解約されません。次回更新日の前日までに解約手続きを完了しない場合、自動更新されます |
| 動作環境 | 【要確定】（対応OSバージョンをストア掲載要件と合わせて記載） |
| 特別条件 | 未成年の方は親権者の同意を得た上でご利用ください |

## 3. 確定に必要な情報（ユーザー提供待ち）

1. 販売事業者名（個人/法人の別を含む）
2. 運営責任者名
3. 所在地・電話番号（または請求時開示とする方針の確認）
4. オラクルアプリ専用のサポートメールアドレスを新設するか、`support@apps2craft.com`を共用するか
5. 対応OSバージョン（ストア申請設定の確定後）
