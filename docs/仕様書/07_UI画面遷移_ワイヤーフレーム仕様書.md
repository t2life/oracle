### 3.1 演出・解釈表現の確定方針（2026-08-31・プロダクトオーナー回答反映）

- **正位置のみ**: オラクルカードに逆位置は存在しない。U-08/U-09でカードの上下反転表現・
  向き別の解釈切替は行わない。
- **素材の使い分け**: カードシャッフル等、画質を重視しない演出箇所は**Lottie動画**、
  オープンされたカード（U-08選択後・U-09結果表示）は**静止画像**を使用する。
- **テーマ6軸**: U-05に表示されるテーマは 潜在意識→ハイヤーセルフ→恋愛→金運→仕事→健康 の
  6件・この表示順（`05_API仕様書.md`§4参照）。

## 5. UI設計方針の遵守状況（追補仕様書2章）

| 方針 | 遵守状況 |
|---|---|
| 1画面1目的 | 各画面が単一責務のFlutter Screenウィジェットとして分離されており準拠 |
| 1カラム中心 | コード上の制約確認は目視レビューが必要（本書は構造面の確認に留まる） |
| 主CTAは上部〜中央 | 同上 |
| タップ領域は広く確保 | 同上（実機での操作性検証は`08_テストケース仕様書.md`のUIテスト観点として未実施） |
| ペイウォールの出し分け（結果直後・履歴制限時・3枚引き選択時） | `PaywallScreen`遷移元の分岐ロジックは個別コード確認が必要 |
| 通知許諾の二段階方式 | `NotificationService.should_prompt_permission(user_id, completed_readings)`がバックエンド側に存在するが、モバイル側での実際の許諾タイミング制御実装は未確認 |
