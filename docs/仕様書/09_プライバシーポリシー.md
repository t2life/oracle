## 2. はじめに

本プライバシーポリシーは、日本神話オラクルロンカード（以下「本アプリ」）において、
お客様の情報をどのように取得し、何に使い、どのように管理するかを定めるものです。

## 3. 取得する情報

本アプリは、サービスの提供に必要な範囲で次の情報を取得します。

| 種類 | 内容 |
|---|---|
| 利用者の識別子 | 端末ごとにアプリが自動で作る利用者ID |
| ログイン情報 | Apple または Google でログインした場合の、各サービスから受け取る識別子とメールアドレス |
| プロフィール | ニックネーム、表示言語 |
| 利用状況 | 訪問回数、登録日時・更新日時 |
| リーディングの記録 | 選んだテーマ・デッキ・カード、結果の文章、**お客様が入力した相談内容** |
| ご契約の状態 | ご利用中のプラン、チケット残数、月額プランの有効期限 |
| 購入の参照情報 | App Store / Google Play が発行するレシートの識別子（二重課金を防ぐために使います） |
| 通知 | プッシュ通知の送信先トークン、通知の種類ごとのオン・オフ設定 |
| お問い合わせ | お問い合わせの種別・本文・ご連絡先メールアドレス |
| 利用の記録 | どの画面が使われたかなどの行動記録（サービス改善のための集計に使います） |
| 操作の記録 | 不正利用の調査と運用監査のための操作ログ |
| 機種引継ぎコード | 機種変更の際にお客様が発行する使い捨てのコード。発行元のアカウントと有効期限を保持します |

## 4. 取得しない情報

- 生年月日・性別・住所などの属性情報は取得しません。
- クレジットカード番号などの決済カード情報は**一切お預かりしません**。
  お支払いは App Store / Google Play が処理し、本アプリはレシートの識別子のみを扱います。
- 位置情報は取得しません。

## 5. 利用目的

1. リーディング（本日の託宣・リーディング）の提供、履歴の保存と表示
2. 会員の管理（ログイン状態、プラン、チケット残数の維持）
3. 購入処理（レシートの確認、購入の復元、二重処理の防止）
4. プッシュ通知・アプリ内お知らせの配信
5. お問い合わせへの対応
6. サービス改善のための利用状況の集計
7. 不正利用の防止とセキュリティ監査
8. 機種変更にともなうアカウントの引き継ぎ

相談内容は、お客様の問いに沿った結果の文章を組み立てるために使います。
本アプリが文章を組み立てるためだけに用い、広告その他の目的には使いません。

## 6. 第三者への提供・委託

法令に基づく場合を除き、お客様の情報を第三者へ提供することはありません。
サービスの提供に必要な範囲で、次の事業者を利用します。

| 連携先 | 渡す情報 | 目的 |
|---|---|---|
| Apple（Sign in with Apple／App Store の決済） | ログイン識別子、レシート情報 | ログインと購入の確認 |
| Google（Google Sign-In／Google Play の決済） | ログイン識別子、レシート情報 | ログインと購入の確認 |
| プッシュ通知基盤（FCM／APNs） | 通知の送信先トークン | 通知の配信 |
| 分析基盤 | 行動の記録 | サービス改善のための集計 |

## 7. 保管期間と削除

- お客様の情報は、サービスの提供に必要な期間、保管します。
- 退会およびデータの削除をご希望の場合は、お問い合わせ窓口から承ります。
- 不正利用の防止を目的とする操作の記録は、削除のご依頼の対象外とし、
  1年を目安に保管したのち削除します。

## 8. お客様の権利

お客様はご自身の情報について、次の請求を行うことができます。

- 開示の請求
- 訂正・削除の請求
- 利用停止の請求
- 第三者提供の停止の請求

アプリ内のお問い合わせフォーム、または末尾の窓口までご連絡ください。

## 9. 端末内への保存について

本アプリは、表示言語・テーマ・ニックネーム・利用者IDなどの設定を、
お客様の端末内に保存します。これらは端末の中だけで使われます。
本アプリはWebブラウザ向けのCookieを利用しません。

## 10. お子さまの利用について

未成年の方は、保護者の同意を得たうえでご利用ください。
とくにアプリ内の購入については、必ず保護者の方の同意を得てください。

## 11. 本ポリシーの変更

本ポリシーは、法令の改正やサービス内容の変更に応じて改定することがあります。
重要な変更を行う場合は、アプリ内でお知らせします。

## 12. お問い合わせ窓口

本ポリシーおよび個人情報の取り扱いに関するお問い合わせは、次の窓口までご連絡ください。

- 提供者: ${販売事業者}（屋号: ${屋号}）
- メール: ${メールアドレス}

## 13. 実装メモ（公開しない）

公開ページには載せない。実装の現況と、公開までに片付ける項目を残す。

- **外部連携は受け口のみ**: Apple/Google の決済検証、FCM/APNs の送信、
  外部分析基盤への送信は API の受け口を用意した段階で、実際の外部通信は未接続
  （`11_今後の開発ロードマップ.md`）。第6条は接続後に実効化される。
- **退会・削除APIは未実装**: 第7条は当面、お問い合わせ経由の手動対応で履行する。
  Phase 1 で API を実装する。
- **監査ログの自動削除は未実装**: 第7条の「1年を目安」は運用方針であり、
  自動削除処理はこれから実装する。
- **年齢確認機構は無い**: 主ターゲットは30〜80代（詳細仕様書4.1章）。
  第10条は同意のお願いに留め、年齢確認の要否はストアのレーティング設定と
  合わせて別途判断する。
- **相談内容の保存**: 2026-09-10 の承認（作業1-3 §C）で保存することを決めた。
  第3条・第5条がこれに対応する。
- **機種引継ぎコード**: 2026-09-11 追加。使い捨て・既定7日間有効。
- **外部AIは使わない（2026-09-11 決定）**: ディープリーディング（外部AIによる
  文章の推敲）は**採用しない**と決めたため、Ver.1.2 で一度入れた「AI事業者」の
  記述を削除した。結果の文章は内蔵エンジンが組み立て、**相談内容が外部へ
  送られることはない**。将来この判断を覆すときは、事業者名を明記して
  再公開してから接続すること。
