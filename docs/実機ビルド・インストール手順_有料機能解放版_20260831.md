## 2. 有料機能解放の仕組み

- `mobile_app/lib/core/state/app_state.dart` の `OracleAppState.premiumUnlocked`
  （`bool.fromEnvironment('PREMIUM_UNLOCKED')`）がビルド時フラグ。
- **`--dart-define=PREMIUM_UNLOCKED=true` を付けたビルドのみ**、起動時
  （`initialize()`）に既存の購入復元API（`POST /purchase/restore`・
  `subscription_monthly_500`）を呼び、サブスクリプション特典
  （3枚引き・履歴無制限・1日1回制限の解除）を有効化する。
- レシートIDは起動ごとにタイムスタンプ付きで発行するため、起動のたびに
  サブスク期限が再付与される（バックエンドInMemory再起動後も自動復旧）。
- フラグ未指定の通常ビルドは従来どおり無料プラン開始（本体挙動に影響ゼロ）。

## 4. ★重要: 日本語パス問題（ビルドはASCIIパスのコピーで行う）

ワークスペース（`...\Desktop\オラクルカード\...`）は日本語を含むため、
**Dart AOTスナップショッタがパスを文字化けで受け取りビルドが失敗する**
（`Unable to read file: C:\...\�I���N���J�[�h\...` / exit 255）。

- `android.overridePathCheck=true`（gradle.properties追加済み）はAGPの検査を
  通すだけで、ネイティブツールの失敗は回避できない。
- ジャンクション（`mklink /J`）もGradleの実パス正規化により**無効だった**（実測）。
- **∴ ビルドは `C:\oracle_build\mobile_app`（実コピー）で行う。**
  ソースの正はワークスペース側であり、ビルド前に必ず同期する。

## 6. 実機で動作させるための必須条件（現状はローカル開発構成）

1. **PC上でバックエンドAPIを起動しておく**:
   `C:\Users\81907\Desktop\オラクルカード\system\.venv\Scripts\python.exe scripts\run_dev_server.py`
2. **USB接続＋`adb reverse tcp:8000 tcp:8000`** を設定する
   （アプリの接続先は`http://127.0.0.1:8000`固定。reverseにより実機のlocalhostが
   PCの8000番へ転送される。**USBを抜くと通信エラーになる**＝仕様）。
3. reverse設定はUSB再接続・adb再起動で消えるため、都度再実行する。

バックエンドはInMemoryのため、サーバー再起動でユーザー・履歴は初期化される
（有料解放はアプリ再起動で自動再付与）。

## 8. トラブルシュート記録（再発時の参照用）

| 症状 | 原因 | 対処 |
|---|---|---|
| AGP「non-ASCII characters」でビルド失敗 | 日本語パス検査 | `android.overridePathCheck=true` |
| AOT snapshotter exit 255 | ネイティブツールの日本語パス文字化け | ASCIIパスの実コピーでビルド（§4） |
| アプリは起動するがAPIに一切到達しない | main ManifestにINTERNET権限がない（releaseの既知の罠） | `<uses-permission android:name="android.permission.INTERNET"/>` |
| 実機スクリーンショットが真っ黒 | 画面消灯（Pixel Foldはマルチディスプレイ警告も出る） | `input keyevent KEYCODE_WAKEUP`→`wm dismiss-keyguard`後に取得 |
