## 2. USBレス動作（3層構成）

| 層 | 実装 | 実機検証結果 |
|---|---|---|
| ① 接続先のビルド時注入 | `app.dart`の`ORACLE_API_BASE_URL` dart-define（ハードコード解消。既定は`http://127.0.0.1:8000`で従来互換） | 本ビルドは`http://192.168.40.50:8000`（PCのWi-Fi IP）を注入 |
| ② Wi-Fi LANオンラインモード | サーバーを`ORACLE_SERVER_HOST=0.0.0.0`でLAN公開（`run_dev_server.py`を環境変数対応化。既定は127.0.0.1のまま） | ✅ サーバーログに実機IP（192.168.40.173）から`/auth/login`→`/purchase/restore`（サブスク有効化）→全初期ロード200を確認。**USB完全不要** |
| ③ オフライン自動フォールバック | `/health`プローブ（**最大2回**・Wi-Fi初回接続のウォームアップ由来の偽陰性対策）失敗時、内蔵マスタ＋端末内保存で単体動作する`OfflineBackend`へ自動切替。ホームにバナー表示、pull-to-refreshで復帰再試行 | ✅ サーバー停止相当の状態で「オフラインモードで動作中」バナー＋メニュー動作＋**有料解放もオフラインで機能**（plan=subscription表示）を実機確認 |

オフラインエンジンの設計原則:

- 抽象IF `OracleBackend` を新設し、`ApiClient`（リモート）と`OfflineBackend`（ローカル）が同一契約
  （API仕様書と同じキー構造のMap/List）を実装。domain_modelsはどちらでも同じにパースされる。
- マスタは `scripts/export_master_assets.py` が**バックエンドシードから生成**する
  `assets/master_data.json`（358KB・3言語・単一真実源）。3山分配・無料日次1回・履歴3件上限・
  シャッフル3条件・チケット/サブスク商品規則もJSONで共有しサーバーと同一規則。
- 端末内保存（SharedPreferences）: プラン/チケット/訪問回数/履歴/日次回数/言語設定。
- サーバー必須機能（問い合わせ送信・通知トークン登録）はオフラインでは
  「オフラインのためこの機能は利用できません」を明示（沈黙させない）。
- 制約: オフラインの日次判定は端末ローカル日付（サーバーはJST）。オフライン中の履歴・
  サブスク状態は端末内のみでサーバーと同期しない（デモ用途では十分）。

## 3. 多言語化（ARB・日本語/English/中文（简体））

| 対象 | 実装 |
|---|---|
| UI文言 | Flutter標準gen-l10n。`l10n.yaml`＋`lib/l10n/app_{ja,en,zh}.arb`（約110キー×3言語）。テンプレートはja |
| 言語切替 | マイページ（U-17）にドロップダウン（システム設定に従う/日本語/English/中文（简体））。選択は端末保存され即時全画面反映（`MaterialApp.locale`） |
| 状態層メッセージ | `StateMessages`コード＋画面側`resolveStateMessage`で解決（状態層はBuildContext非依存を維持）。サーバー返却文言はそのまま表示 |
| コンテンツ（マスタ） | バックエンドの`Theme/Deck/Card/ReadingResult`へ`name_en/name_zh`・`keywords_en/zh`・`interpretation_text_en/zh`・`caution_text_en/zh`等を**追加フィールドとして**実装（後方互換）。シードは3言語生成。API応答・オフライン資産の両方に搭載 |
| 表示選択 | `domain_models`の`nameFor/keywordsFor/interpretationFor(languageCode)`（en/zh欠落時はjaフォールバック） |

実機検証（スクリーンショット取得済み）:

- 日本語: オンボーディング（従来の英語ハードコードが日本語化）
- English: My Page全文言＋「Premium build: subscription benefits activated.」
- 中文: 我的页面全文言＋**牌组选择**（日本神话牌组/龙神牌组/布莱斯娃娃牌组）＋
  **主题选择**（潜意识→高我→爱情→财运→事业→健康＝承認済み6軸の中国語・承認順）

制限事項（今後の課題）: 履歴の保存本文はja固定（サーバーHistoryItemスキーマ準拠）。
商品タイトル・お知らせ本文はサーバー運用コンテンツのためja（コンテンツCMSの多言語化は将来スコープ）。
アプリ名（ブランド）は3言語共通で日本語表記（ローカライズはオーナー判断事項）。

## 5. 発見・解決した問題

| 問題 | 真因 | 解決 |
|---|---|---|
| gen-l10nが「arb-dir doesn't allow reading and writing」で失敗 | `lib\l10n`ディレクトリに読み取り専用属性(R)が付与されていた | `attrib -R`で解除（ソースとビルドコピー両方） |
| サーバー到達可能なのに初回起動がオフラインへ倒れる | Wi-Fi初回接続のウォームアップでヘルスプローブ（3秒）がタイムアウト（サーバーログには200が記録＝偽陰性を実測） | プローブを最大2回試行へ変更し実機で解消を確認 |

## 6. 運用メモ

- 実機がオンラインモードで動く条件: PCでサーバー起動（`ORACLE_SERVER_HOST=0.0.0.0`）＋実機とPCが同一Wi-Fi。**USB・adb reverseは不要になった**。
- PCのIPが変わった場合（DHCP）: アプリは自動でオフラインモードにフォールバックして動き続ける。オンラインへ戻すには新IPで`--dart-define=ORACLE_API_BASE_URL=...`を指定して再ビルド。
- マスタ変更時の一手順: シード変更 → `export_master_assets.py`再実行 → モバイル再ビルド（オフライン側の乖離防止）。
- 本番リリース時: 接続先を本番URL（HTTPS）にし、`usesCleartextTraffic`削除・正式署名（既存手順書§9のとおり）。
