## 1. Mac でやること（順番どおりに）

### 1-1. 取得とビルド確認【最優先】

```bash
git clone https://github.com/t2life/oracle.git ~/oracle
cd ~/oracle
git checkout feature/20260909-home-6fix
cd system/mobile_app
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
```

`flutter analyze` は「No issues found!」、`flutter test` は **52 件 green** になること。

**置き場所は ASCII のパスにする**（`~/oracle` など）。
Windows 側は日本語を含むパスの下に置いているが、
**日本語パスは CocoaPods が転ぶことがある**。Mac は git から取るので問題にならない。

> Windows で使っている `C:\oracle_build\mobile_app` への複製は
> **Windows 固有の回避策**であり、Mac では不要。

### 1-2. `flutter gen-l10n` を忘れると何もコンパイルできない

`mobile_app/lib/l10n/app_localizations*.dart` は **`.gitignore` の 38 行目で除外**している
（生成物のため）。∴ clone 直後は存在せず、`AppLocalizations` が解決できずに全滅する。

`.arb`（`app_ja.arb` / `app_en.arb` / `app_zh.arb`）は追跡しているので、
`flutter gen-l10n` を1回走らせれば復旧する。

### 1-3. 初回 iOS ビルド

```bash
open ios/Runner.xcworkspace
```

`Podfile` はここまでの flutter コマンドで生成される。
Xcode で **Runner → Signing & Capabilities → Team** を設定する。

> 先行アプリ（十二天水地暦）が **Apple Developer Team `D7THUVNT5T`** を使っている
> （`jyuuni-tensui-chireki/iphone/iosApp/iosApp.xcodeproj/project.pbxproj` L289）。
> 同じ提供元（Apps2Craft）なので、**同じチームを使えるはず**である。要確認。

### 1-4. マスタは Mac では作り直せない（作り直す必要も無い）

| 置き場 | 内容 | git |
|---|---|---|
| `Desktop\オラクルカード\DB\*.xlsx` | カードDBの原本 | **リポジトリ外**（Windows のみ） |
| `Desktop\オラクルカード\カード図柄\` | 印刷用の図柄 | **リポジトリ外**（Windows のみ） |

## 2. iOS で決めなければならないこと

### 2.1 Bundle ID が Android と揃っていない【要判断・後戻り不可】

| | 値 |
|---|---|
| Android `applicationId` | `com.apps2craft.oracle_mobile_app` |
| iOS `PRODUCT_BUNDLE_IDENTIFIER` | `com.apps2craft.oracleMobileApp` |

iOS 側は Flutter のテンプレートが機械的に作った綴りで、**誰も決めていない**。
**App Store へ提出したあとは変更できない**ため、提出前に確定させる。

| 案 | 内容 |
|---|---|
| A | `com.apps2craft.oracle` に揃える（短く、アプリ名に近い） |
| B | iOS も `com.apps2craft.oracle_mobile_app` にする（Android と完全一致。ただし `_` は慣例的でない） |
| C | 現状のまま `com.apps2craft.oracleMobileApp` |

> 変更する場合は Runner だけでなく、`RunnerTests` 側の3箇所も追従する。

### 2.2 ATS（`NSAllowsArbitraryLoads`）を落とす【審査に関わる】

`ios/Runner/Info.plist` に開発用の例外が入っている。

```xml
<key>NSAppTransportSecurity</key>
<dict><key>NSAllowsArbitraryLoads</key><true/></dict>
```

直前のコメントに「本番はHTTPS化のうえ、このブロックを削除すること」と書いてある。
実機確認では `--dart-define=ORACLE_API_BASE_URL=http://192.168.x.x:8000` で
LAN のサーバーに繋ぐため**開発中は必要**だが、**提出ビルドでは削除する**。
Apple は無条件の `NSAllowsArbitraryLoads` に理由の説明を求める。

> サーバーを立てずに動かすこともできる。オフライン経路（`OfflineBackend`）が
> 同じ文章・同じ結果を返すため、**UI の確認だけなら `--dart-define` 無しでよい**。

### 2.3 課金（IAP）が**まだ何も無い**【最大の未実装】

| 層 | 実態 |
|---|---|
| Flutter | **StoreKit / IAP のプラグインが入っていない**（`in_app_purchase` 等なし） |
| 購入処理 | `POST /purchase/verify` にクライアントが作った `receipt_id` を送るだけ |
| サーバー検証 | `AppleStoreKitVerifier` の**骨格だけ**。実接続は未実装で **fail-closed**（必ず検証失敗） |
| 環境変数 | `ORACLE_APPLE_ISSUER_ID` / `ORACLE_APPLE_KEY_ID` / `ORACLE_APPLE_PRIVATE_KEY` は定義済み |

`receipt_verification.py` の既定は `local`（形式チェックのみ）で、
production では起動拒否の対象になる設計（`orchestrator._build_receipt_verifier`）。

**iOS で課金を通すには次が要る。**

1. App Store Connect で商品を登録（`store.py` の5商品に対応）
2. Flutter に IAP プラグインを入れ、購入フローを実装
3. `AppleStoreKitVerifier.verify()` に App Store Server API の実接続を実装
4. `StoreApiReceiptVerifier` の**プラットフォーム判別**を実装（現在は未実装で fail-closed）

> **先行アプリに参考実装がある**:
> `jyuuni-tensui-chireki/iphone/iosApp/iosApp/Billing/StoreKitSubscriptionGateway.swift`
> ／ 手順は `docs/106_修正方針_課金IAPと広告_フリーミアム実装計画` と
> `docs/107_手順_課金と広告のストア準備_P0`。
> ただし先行アプリは Kotlin Multiplatform＋Swift、本アプリは Flutter なので
> **移植ではなく読み替え**になる。

現状の価格（税込・`store.py`）: チケット 330 / 550 / 1100 / 2200 円、月額 550 円。

### 2.4 ストアの掲載URLに iOS 用の入れ物が無い

`mobile_app/lib/core/config/app_links.dart` は
`androidPackageName` と `storeListingUrl`（現在は空）しか持たない。
iOS では App Store の URL が別になるため、**プラットフォームで出し分ける**必要がある。

「アプリを評価」「アプリを共有」の2箇所が参照する。
**空のままなら押せない状態**になるので、iOS 提出までは触らなくても壊れない。

## 3. iOS でだけ起きる可能性のある挙動【実機で確かめる】

いずれも**未確認**である。推測で直さず、実機で見てから判断すること。

### 3.1 音（マナーモードと、2つのプラグインの取り合い）

`SoundService` は `AudioPlayer` を2つ持つ（効果音・環境音）が、
**`AudioContext` を設定していない**（`lib/core/audio/sound_service.dart` L34-35）。

- iOS は**消音スイッチ**で音を止めるかどうかが AVAudioSession のカテゴリで決まる。
  意図した挙動（占いの効果音を鳴らすか、マナーモードでは黙るか）を決めて設定する。
- ホーム画面は `video_player` で `character_home.mp4` を再生する。
  **`audioplayers` と `video_player` が同じ AVAudioSession を奪い合う**のは
  iOS でよくある不具合で、片方が無音になる／再生が止まることがある。

### 3.2 共有（iPad で落ちる）

`app_actions.dart` L40 が `Share.share(...)` を呼んでいる。
**iPad では `sharePositionOrigin` を渡さないと例外になる**（iOS 固有）。
iPhone のみ配信なら顕在化しないが、iPad 対応するなら必須。

### 3.3 テーマ画像（写真ライブラリ）

`my_page_screen.dart` が `image_picker` で選んだ画像を
アプリ領域へコピーして `FileImage` で表示する。
`NSPhotoLibraryUsageDescription` は設定済み（日本語文あり）。
**iOS は権限拒否時の復帰経路**が Android と違うため、拒否→再選択の導線を確認する。

### 3.4 戻る操作

Android の戻るキー対策（`_handleSystemBack` ／ フロー離脱の確認ダイアログ）を入れているが、
**iOS には戻るキーが無く、代わりにスワイプバックがある**。
占いフローの途中で意図せず戻れてしまわないか確認する。

### 3.5 カードの縦横比

`kOracleCardAspect = 120 / 70`（実物の寸法）。
機種ごとの画面比で見切れが出ないか、iPhone SE 級の小さい画面で確認する。
